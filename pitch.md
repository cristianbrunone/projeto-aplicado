## ⏱️ Estrutura do Pitch (3 minutos)

### **[0:00 - 0:30] Abertura - O Problema** (30 segundos)

**Visual:** Mostrar tela inicial do sistema / Logo

**Narração:**
> "Imagine uma empresa que perde tempo procurando peças, não sabe quando o estoque está acabando, e tem dificuldade em acompanhar ordens de serviço. Esse é um problema real que afeta a produtividade de muitas organizações. Nossa solução? Um sistema completo de gestão de estoque e manutenção desenvolvido especialmente para o SENAI."

**Pontos-chave:**
- Problema: desorganização no controle de estoque
- Impacto: perda de tempo e produtividade
- Contexto: demanda real do SENAI ES

---

### **[0:30 - 1:30] A Solução - Demonstração Rápida** (60 segundos)

**Visual:** Navegação rápida pelas principais telas

**Narração:**
> "Nosso sistema oferece três plataformas integradas: Web, Mobile e uma API robusta. Vamos ver rapidamente o que ele faz:"

**Demonstrar (15 segundos cada):**

1. **Dashboard Web** (0:30-0:45)
   - Mostrar dashboard com visão geral
   - "Aqui temos uma visão completa do estoque em tempo real, com alertas automáticos quando peças estão acabando"

2. **Gestão de Peças** (0:45-1:00)
   - Mostrar listagem e cadastro rápido
   - "Cadastro simples de peças com controle de quantidade mínima e máxima"

3. **Ordens de Serviço** (1:00-1:15)
   - Criar uma ordem de serviço
   - "Criação e acompanhamento de ordens de serviço com atribuição de técnicos"

4. **Mobile** (1:15-1:30)
   - Mostrar app mobile em funcionamento
   - "E tudo isso disponível no celular para técnicos em campo"

---

### **[1:30 - 2:15] Tecnologia e Diferenciais** (45 segundos)

**Visual:** Diagrama de arquitetura / Logos das tecnologias

**Narração:**
> "Desenvolvemos uma arquitetura moderna e escalável:"

**Destacar:**
- **Backend:** Python com Flask e PostgreSQL - robusto e confiável
- **Frontend Web:** React.js - interface moderna e responsiva
- **Mobile:** Flutter - multiplataforma (Android e iOS)
- **Infraestrutura:** Docker - fácil deploy e manutenção

**Diferenciais:**
- ✅ Sistema completo (Web + Mobile + API)
- ✅ Alertas automáticos de estoque baixo
- ✅ Sincronização em tempo real
- ✅ Arquitetura profissional (MVVM, Clean Architecture)
- ✅ Fácil de instalar com Docker Compose

---

### **[2:15 - 2:45] Impacto e Resultados** (30 segundos)

**Visual:** Gráficos ou números de impacto (se houver dados de teste)

**Narração:**
> "Com nosso sistema, as empresas podem:"

**Benefícios:**
- 📊 **Reduzir tempo de busca** por peças e informações
- 🔔 **Evitar falta de estoque** com alertas automáticos
- 📱 **Mobilidade** para técnicos em campo
- 📈 **Melhor controle** de ordens de serviço
- 💰 **Economia** com melhor gestão de recursos

## 🎥 Dicas para Gravação

### Preparação
- [ ] Testar todas as funcionalidades antes de gravar
- [ ] Preparar dados de exemplo realistas
- [ ] Limpar notificações e abas desnecessárias
- [ ] Usar resolução 1920x1080 para gravação
- [ ] Testar áudio e microfone

### Durante a Gravação
- [ ] Falar de forma clara e pausada
- [ ] Manter energia e entusiasmo
- [ ] Seguir o tempo rigorosamente (3 minutos)
- [ ] Mostrar apenas o necessário (não se perder em detalhes)
- [ ] Usar transições suaves entre telas

### Edição
- [ ] Adicionar música de fundo sutil (opcional)
- [ ] Incluir legendas para pontos-chave
- [ ] Adicionar animações de transição
- [ ] Destacar elementos importantes na tela (zoom, círculos)
- [ ] Verificar duração final (máximo 3 minutos)

## 📝 Script Alternativo (Mais Técnico)

Se o público for mais técnico, use esta variação:

### **[1:30 - 2:15] Tecnologia (Versão Técnica)**

**Narração:**
> "A arquitetura do sistema segue as melhores práticas de desenvolvimento:"

- **Backend:** API RESTful em Python/Flask com SQLAlchemy ORM
- **Banco de Dados:** PostgreSQL com migrations automáticas
- **Frontend:** React.js com Vite, React Router e Axios
- **Mobile:** Flutter com arquitetura MVVM e Riverpod para state management
- **Deploy:** Docker Compose para orquestração de containers
- **Versionamento:** Git com CI/CD via GitHub Actions
